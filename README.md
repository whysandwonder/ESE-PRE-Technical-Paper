# UPSC ESE Prelims Paper II PYQ Portal (2017–2026)

Every question from UPSC Engineering Services (Preliminary) **Paper II** for **Civil, Mechanical, Electrical and Electronics & Telecommunication Engineering**, 2017 to 2026: 6,000 questions (1,500 per branch) with full answer analysis. Pick your branch once; the portal remembers it (change it any time from the top bar).

- Practice subject-wise or paper-wise, or take random timed tests with UPSC marking (+2, −0.67)
- Every option and statement explained; numericals worked step by step, with figures
- **Analysis**: how often each subtopic is asked, with all-years and recent-trends views
- Bookmarks, progress tracking and night mode; works on phones
- **Install as an app** and use it offline
- Progress is saved in your browser, per branch; use **My data** to back it up or restore it

## Answer keys

- **2017–2024**: UPSC's official final answer keys. Each question was also solved independently; where our working disagrees, the question is marked "In doubt" with an explanation (the official key is still shown as the answer).
- **2025–2026**: UPSC has not published official keys yet. Answers were solved independently and checked against the MADE EASY unofficial key; where we believe that key is wrong, our verified answer is shown and the difference is explained.

## Publish with GitHub Pages

1. Create a **public** repository and upload everything in this folder (keep the `data` and `img` folders). GitHub's web page takes at most 100 files per upload, so use the ready-made batches in the `-upload` folder next to this one (see `HOW TO UPLOAD.txt` there), or push with git.
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then click **Save**.
3. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Use it on your own computer (no GitHub needed)

Double-click **Start portal (Windows).bat**. It opens the portal at `http://localhost:8790/`, where the **Install app** button works. Opening `index.html` directly (a `file://` page) works for practice, but browsers do not allow installing or offline copies from it. Once installed, the app opens from the Start menu and works offline even when the launcher is closed.

## Install as an app

- **Android (Chrome)**: open the link → **Install app** button in the top bar, or ⋮ → *Add to Home screen* → *Install*.
- **Windows / Mac (Chrome or Edge)**: the **Install app** button, or the install icon in the address bar.
- **iPhone / iPad**: open in **Safari** → **Share** → **Add to Home Screen**.

Open it once while online; after that all four branches work without internet. After you upload a new version, the installed app updates the next time it is opened online. Saved progress stays.
